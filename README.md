# breast-calculator

Калькулятор объёма и веса женской груди и европейского размера бюстгальтера.
Сюжет шутливый, подход всерьёз: формулы взяты из рецензируемых работ, и везде
помечено, что из этого валидировано, а что - эвристика без независимой проверки.

Вход: обхват груди и обхват под грудью (обычная сантиметровая лента).
Выход: европейский размер вида "75B", объём и вес одной груди с 95%
доверительным интервалом, а также разбор того, откуда взялась каждая цифра.

> Точный вес одной груди в быту измерить нельзя, поэтому все оценки даются
> интервалами. Это медицинская оценка, а не приговор: реальные значения зависят
> от плотности ткани, формы, возраста и ИМТ.

## Быстрый старт

Нужен Python 3.8+. Сторонних зависимостей нет - только стандартная библиотека.

```cmd
py breast_calculator.py 88 75
```

Пример вывода:

```

Входные данные:
  Обхват груди: 88 см
  Обхват под грудью: 75 см
  Разница: 13 см

Размер (конвенция ритейлеров с шагом чашки 2 см; формально это не стандарт EN 13402-3):
  Бандаж: 75
  Чашка: B (diff 12-14 см)
  Итог: 75B
  Sister sizes: 80A, 70C

Модель объёма: эвристическая (fallback; не валидирована)
  Объём одной груди: 390 мл (95% ДИ: 164-617 мл)

  Вес одной груди: 375 г (95% ДИ: 151-598 г)

Погрешность объёма: модель ±20% + измерения ±21.8% (через производные по входам) = ±29.6%

  Итог для веса (95% ДИ): ±59.6%
```

## Три модели объёма

| Модель | Что нужно вводить | Статус |
|---|---|---|
| `heuristic` (по умолчанию) | только два обхвата | эвристика, НЕ валидирована |
| `qiao` | 4 линейных измерения: `--mp --lr --mr --ir` | антропометрическая формула 1997 г., валидации по образцам не было |
| `breast-v` | 3 линейных измерения: `--notch-nipple --fold-nipple --fold-projection` | самая валидированная: 108 мастэктомических образцов, MAE 89.7 г (18.4%) |

Как снять измерения дома (все - стоя, расслабленно, без утягивающего белья;
каждое повторить 2-3 раза и усреднить):

- **Обхваты.** BUST - лента по горизонтали через самые выступающие точки;
  UNDERBUST - непосредственно под грудью, по уровню инфрамаммарной складки.
- **Проекции (для qiao и breast-v).** Встаньте боком к зеркалу и приложите к
  грудной стенке плоский предмет (линейку или коробку) торцом вперёд - он
  "продолжит" грудную стенку; все проекции меряются от него по горизонтали.
- **Дистанции (для breast-v).** От яремной вырезки (впадина между ключицами)
  до соска и от соска до инфрамаммарной складки - по поверхности тела.

Все модели дают объём одной груди; измеряйте обе стороны по отдельности,
чтобы учесть асимметрию (левая в среднем чуть больше - это нормально).

Дополнительные флаги: `--age`, `--bmi` (корректируют долю железистой ткани),
`--glandular-fraction` (если доля известна, например по маммографии),
`--measurement-error` (ошибка измерения, см; дома берите 0.5-1.0).

## Проверка согласованности

```cmd
py breast_calculator.py --self-check
```

Сравнивает эвристику с опубликованными якорями из статей (Huang 2017:
объёмы по чашкам A/B/C/D; Qiao 1997: средний объём молодых китаянок;
популяционные диапазоны; MRI-волюметрия Behrens 2024). Важно и честно:
это проверка согласованности, а НЕ независимая out-of-sample валидация -
константа эвристики откалибрована по части этих же якорей. Научная
валидация требует независимой когорты, которой у проекта нет.

## Методика (кратко)

1. **Размер.** Бандаж - округление обхвата под грудью к кратному 5 см
   (65, 70, 75...); чашка - по разнице обхватов с шагом 2 см (AA, A, B...).
   Это конвенция ритейлеров, а не буквальный EN 13402-3.
2. **Объём.** Три модели (см. таблицу выше). Fallback-эвристика:
   `V ≈ 2.31 · diff² · (band / 75)` - калибрована по среднему двух
   опубликованных якорей.
3. **Плотность.** Кусочно-линейная интерполяция по ICRU Report 44:
   жировая 0.95, таблица 50/50 - 0.96, железистая (фиброгландулярная)
   1.02 г/см³. По умолчанию g = 0.5 (средняя доля железистой ткани
   по маммографии ~42.5%).
4. **Вес.** W = V·ρ; доверительный интервал собирается из ошибки модели,
   ошибки измерений (через частные производные формулы объёма по каждому
   входу) и разброса плотности.

Полная методика и список из ~15 источников (Longo 2013, Huang 2017,
Qiao 1997, ICRU 44, Behrens 2024 и др.) - в docstring модуля
`breast_calculator.py`.

## Честные ограничения

- Эвристическая fallback-модель по двум обхватам не имеет peer-reviewed
  первоисточника: формулы "обхваты -> объём" в литературе нет.
- Поправки по возрасту/ИМТ - рукописные плейсхолдеры, а не регрессии.
- Результат зависит от самооценённого размера чашки (якоря Huang) и
  техники измерения; разброс внутри когорт большой (340 ± 109 мл).
- Асимметрия выводится как статистическая тенденция, а не прогноз.
